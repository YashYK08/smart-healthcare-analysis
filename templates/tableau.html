Tableau Workbook Calculated Fields Specification
8 Custom Calculated Fields
Calculated Field Name Tableau Formula Clinical Justification
[Calibrated Risk Score] (([age] - 18) / 61 * 25) + MIN(30, ([heart_disease] + [diabetes] + [stroke]) * 10) + (IF [blood_pressure] >= 140 THEN 8 ELSEIF [blood_pressure] >= 130 THEN 5 ELSEIF [blood_pressure] >= 120 THEN 2 ELSE 0 END) + ... Multi-factor clinical risk index replacing the degenerate constant raw score. Scaled 0-100.
[Risk Tier] IF [Calibrated Risk Score] < 35 THEN 'Low' ELSEIF [Calibrated Risk Score] < 55 THEN 'Moderate' ELSEIF [Calibrated Risk Score] < 75 THEN 'High' ELSE 'Critical' END Stratifies patient population into 4 actionable clinical priority tiers.
[Cardiovascular Risk Flag] IF [blood_pressure] >= 140 OR [cholesterol] >= 240 THEN 'Elevated CVD Risk' ELSE 'Normal CVD Risk' END Identifies hypertension or hypercholesterolemia requiring cardiology referral.
[Metabolic Syndrome Marker] IF [bmi] >= 30.0 AND [glucose] >= 126 AND [blood_pressure] >= 130 THEN 'High Metabolic Risk' ELSE 'Standard' END Flags triad of obesity, hyperglycemia, and elevated blood pressure.
[Comorbidity Flag] IF ([heart_disease] + [diabetes] + [stroke]) >= 2 THEN 1 ELSE 0 END Flags dual or triple chronic condition presence for integrated care delivery.
